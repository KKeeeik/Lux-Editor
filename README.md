# LuxDialogues Editor

**可视化对话流编辑器** — 为 LuxDialogues 插件设计的 YAML 配置工具。  
支持图表/列表双视图、暗色模式、富文本对话编辑与完整的配置面板，让对话树的创作更直观。

🌐 **在线使用**：https://luxdialogues-editor.netlify.app/

> ⚡ 本项目界面及代码由 AI 辅助生成，如有问题或建议，欢迎提交 Issue。

---

## ✨ 功能特性

- 🧩 **图表模式** — 拖拽节点、连线跳转，以可视化方式构建对话流
- 📋 **列表模式** — 表格化表单编辑，适合键盘流用户
- 🌗 **亮色/暗色模式** — 一键切换，舒适护眼
- 📥 **导入/导出** — 支持 YAML 文件粘贴导入、文件选择导入，导出可自定义文件名
- 🎨 **颜色系统** — 内置 MC 格式码（`&l` `&n` `&m` `&o`）和十六进制颜色渲染，实时预览
- ⚙️ **配置编辑器** — 可视化编辑 Settings、Sounds、Offsets、Character、Images、Colors，无需手写 YAML
- 🖱️ **右键菜单** — 节点/画布右键：复制、粘贴、更改颜色、删除、新建
- ✏️ **富文本对话编辑** — 双击节点弹窗，支持粗体、斜体、下划线、删除线、颜色选择，所见即所得预览
- 🔗 **智能连线** — 拖拽选项圆点自动绑定 `goto`，并支持条件跳转
- 🗂️ **多文件管理** — 侧边栏新建/切换/删除文件，搜索过滤
- 🔄 **数据持久化** — 切换文件自动保存，内容不丢失
